  <h1>Prenot@Mi Appointment Watcher Privacy Policy</h1>
  <p>Last updated: 2026-03-17</p>

  <p>Prenot@Mi Appointment Watcher is a browser extension for Chrome and other Chromium-based browsers. Its single purpose is to help the user monitor the already opened Prenot@Mi Services page and notify the user when a booking page is detected.</p>

  <h2>What data the extension handles</h2>
  <p>The extension stores local configuration and runtime state using the browser storage API. This may include selected counters, polling interval, notification preferences, debug setting, monitoring state, and the ID of the monitored browser tab.</p>

  <p>The extension also reads the content of the user-opened page on https://prenotami.esteri.it/ in order to find the relevant service row, detect the booking button, detect known availability-error dialogs, and detect whether the page URL changed to a booking page.</p>

  <h2>How the data is used</h2>
  <p>The data is used only to provide the extension’s single purpose and user-facing functionality: monitoring the user-selected Prenot@Mi Services page and alerting the user when a booking page is detected.</p>

  <h2>Data sharing</h2>
  <p>The extension does not sell, transfer, or share user data with third parties.</p>

  <h2>Remote code</h2>
  <p>The extension does not load or execute remote JavaScript or WebAssembly code. All executable logic is packaged within the extension.</p>

  <h2>Data storage</h2>
  <p>All saved settings and state are stored locally in the user’s browser via chrome.storage.local.</p>
